Features

Everything you need to tune

🎯
YIN algorithm
Pitch detection with the YIN algorithm in pure TypeScript. Threshold 0.10, Hann window, parabolic interpolation for maximum accuracy.
⚡
Low latency
Float32Array ring buffer with copyWithin. 50% overlap and UI updates at 30 Hz.
📡
Over-the-air updates
Updates via EAS Update without publishing a new store release. development, preview, and production channels.
🎸
6 standard strings
E2 · A2 · D3 · G3 · B3 · E4. Interactive grid highlighting the string closest to the detected frequency.
📊
Animated needle
Visual cents indicator with native spring animation. Color feedback for flat, in tune, and sharp in real time.
🔇
Silence gate
RMS gate to ignore ambient noise. Simple EMA (α=0.25) smooths readings without masking transients.
